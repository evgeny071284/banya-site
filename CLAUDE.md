# Сайт бани

## О проекте
Лендинг для частной бани. Одностраничный статичный сайт с секциями: услуги, бронирование, о нас, контакты.

## Технологии
- HTML5
- Tailwind CSS (через CDN) — стилизация
- Vanilla JavaScript — интерактивность
- FormSubmit.co — обработка формы бронирования (заявки на email, без бэкенда)

## Структура
```
index.html        — главная страница
css/style.css     — дополнительные стили поверх Tailwind
js/main.js        — скрипты (меню, прокрутка, анимации)
assets/images/    — фотографии и изображения
памятки/          — заметки по проекту
```
