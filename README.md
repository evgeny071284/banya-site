# Сайт бани

Лендинг для частной бани — каталог услуг, форма бронирования, контакты, страница о создателях.

## Как открыть

Просто открой `index.html` в браузере — никаких установок не нужно.

## Как опубликовать

Вариант 1 — **GitHub Pages** (бесплатно):
1. Залей код на GitHub
2. Settings → Pages → выбери ветку main
3. Сайт появится по адресу `username.github.io/banya-site`

Вариант 2 — **Netlify** (бесплатно, проще):
1. Зайди на netlify.com
2. Перетащи папку проекта в браузер
3. Получи ссылку на сайт

## Структура проекта

```
index.html        — главная страница
css/style.css     — дополнительные стили
js/main.js        — JavaScript
assets/images/    — фотографии (добавь свои)
памятки/          — заметки и документация
```

## Форма бронирования

Используется [FormSubmit.co](https://formsubmit.co) — бесплатный сервис.
Нужно заменить `your@email.com` в `index.html` на свой email.
